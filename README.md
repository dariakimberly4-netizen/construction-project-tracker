# Construction Project Tracker

Orbit-first responsive construction management web app.

## Modules
- Projects
- Daily Progress
- Workers
- Materials
- Costs
- Schedule
- Site
- Reports

## Professional features represented
- Purchase Requests & Approvals
- Supplier Management
- Change Orders
- Progress Billing
- Site Inspection
- Safety & Incident Reporting
- Document Vault
- Audit Trail

## Run
Open `index.html` locally, or publish the repository using GitHub Pages.

## GitHub Pages
Repository Settings → Pages → Deploy from branch → `main` / root.
